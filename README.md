# Interlake Health Initiative

A React + Vite site for the Interlake Health Initiative — community health kits, awareness campaigns, and mentorship for families and future healthcare professionals.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Site structure

- **Hero** — mission statement and layered impact stats (including **90 health kits** delivered)
- **Impact** — kit program highlight and contents
- **Programs** — initiatives and outreach
- **Contact** — volunteer, partner, and event information
